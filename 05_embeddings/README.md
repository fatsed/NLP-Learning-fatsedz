# 05 — Embeddings and Similarity

This folder contains practice notebooks for representing words as vectors and measuring similarity between words and sentences.

## Notebooks

- `01_word2vec_train.ipynb` — trains a Word2Vec model on text data
- `02_pretrained_word2vec.ipynb` — works with pretrained Word2Vec embeddings
- `03_persian_word2vec.ipynb` — explores Word2Vec with Persian text
- `04_similarity_distance.ipynb` — compares similarity and distance measures and visualizes word embeddings

## Topics Covered

- Training Word2Vec models
- Pretrained word embeddings
- English and Persian word embeddings
- Cosine similarity
- Euclidean distance
- Manhattan distance
- Levenshtein distance
- Jaccard similarity
- Fuzzy string matching
- Sentence similarity
- Visualizing word embeddings with t-SNE

## How to Run

1. Open a notebook in Jupyter Notebook or Google Colab.
2. Install the required libraries if needed.
3. Upload or load the required text data or pretrained model.
4. Run the cells from top to bottom.
