# 06 — University Coursework

This folder contains the exercises and projects completed as part of my university Natural Language Processing course.

The folders follow the main topics covered during the course, from introductory text processing to machine learning projects.

## Coursework

- `01_WordCloud` — creating word clouds and text visualizations
- `02_TextExtraction` — extracting text from files and web sources
- `03_Tokenization` — tokenizing English text
- `04_NewsNLP` — applying NLP techniques to news text
- `05_WordSimilarity` — measuring word similarity
- `06_Persian_Preprocessing` — cleaning and preprocessing Persian text
- `07_ML_Algorithms` — practicing machine learning algorithms
- `08_Hazm_Pipeline` — building a Persian NLP pipeline with Hazm
- `09_Sklearn_10_Models` — comparing multiple scikit-learn models
- `10_FakeReviews_Project` — detecting fake reviews using NLP and machine learning

## Topics Covered

- Text extraction and preprocessing
- English and Persian NLP
- Tokenization
- Word similarity
- Feature extraction
- Text classification
- Machine learning model comparison
- Fake review detection

## Tools

- Jupyter Notebook / Google Colab

## How to Run

1. Open the required folder.
2. Open its notebook in Jupyter Notebook or Google Colab.
3. Install the required libraries if needed.
4. Run the cells from top to bottom.
