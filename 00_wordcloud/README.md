# 00 — Word Cloud

This folder contains an introductory notebook for creating and displaying word clouds from text.

## Notebook

- `wordcloud (1).ipynb` — creates a word cloud using Python and displays the result with Matplotlib.

## Topics Covered

- Basic text visualization
- Word frequency representation
- Creating and displaying word clouds
- Customizing the appearance of a word cloud

## Tools

- Python
- Jupyter Notebook / Google Colab
- WordCloud
- Matplotlib

## How to Run

1. Open the notebook in Jupyter Notebook or Google Colab.
2. Install the required libraries if needed.
3. Run the cells from top to bottom.
