# 01 — Text Extraction

This folder contains practice notebooks for extracting text and data from websites, APIs, and online datasets.

## Notebooks

- `01_text_url.ipynb` — extracts text from a web page
- `02_web_scraping.ipynb` — practices basic web scraping
- `03_api_request_urllib3.ipynb` — sends API requests with urllib3
- `04_api_error_handling.ipynb` — handles common API errors
- `05_api_with_params.ipynb` — sends API requests with parameters
- `06_api_with_params_universities.ipynb` — retrieves university data from an API
- `07_uci_student_performance_download.ipynb` — downloads a dataset from the UCI repository
- `08_kaggle_api_mobile_reviews.ipynb` — downloads a mobile reviews dataset using the Kaggle API

## Topics Covered

- Extracting text from URLs
- Web scraping
- Working with APIs
- Request parameters
- Error handling
- Downloading online datasets

## Tools

- Python
- Jupyter Notebook / Google Colab
- Requests
- BeautifulSoup
- urllib3
- Kaggle API

## How to Run

1. Open a notebook in Jupyter Notebook or Google Colab.
2. Install the required libraries if needed.
3. Run the cells from top to bottom.
4. Add API credentials or datasets locally when required.

Private API credentials should not be committed to the repository.
