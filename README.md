# NLP Coursework and Practice

This repository contains the notebooks and exercises I worked on during my university Natural Language Processing course.

I created it to keep my NLP practice organized and to document what I learned while working with both English and Persian text.

## Repository Structure

| Folder | Content |
|---|---|
| [`00_wordcloud`](00_wordcloud) | Creating word clouds and basic text visualizations |
| [`01_text_extraction`](01_text_extraction) | Extracting text from websites, URLs, APIs, and datasets |
| [`02_text_cleaning`](02_text_cleaning) | Cleaning text, tokenization, stopword removal, stemming, and lemmatization |
| [`03_practice`](03_practice) | Practice exercises involving news text, NER, frequency analysis, and similarity |
| [`04_vectorization`](04_vectorization) | One-Hot Encoding, Bag of Words, TF-IDF, and text classification |
| [`05_embeddings`](05_embeddings) | Word embeddings, similarity and distance methods, and visualizations |
| [`06_coursework`](06_coursework) | Class exercises and university NLP projects |

## Topics I Practiced

- Text extraction and web scraping
- English and Persian text preprocessing
- Tokenization and stopword removal
- Stemming and lemmatization
- Part-of-Speech tagging
- Named Entity Recognition
- Bag of Words and TF-IDF
- Word2Vec and semantic similarity
- Text classification using machine learning
- Persian NLP with Hazm

## Running the Notebooks

Most notebooks were created in Google Colab.

To run one of them:

1. Open the notebook.
2. Run the cells from top to bottom.
3. Install the required packages when needed.
4. Upload any required datasets locally.

Private files and API credentials, such as `kaggle.json`, should not be added to the repository.

## About This Repository

This is a learning repository, so some notebooks are simple exercises while others combine several NLP steps into a small project. I plan to improve and organize the notebooks as I continue learning.
